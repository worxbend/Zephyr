Zephyr wraps SDKMAN’s CLI and local filesystem. It doesn’t replace your package manager, and it doesn’t make cleanup decisions for you.

One view of your toolchains

See installed JDKs and SDKs, their versions, and persisted defaults. Search your workspace without jumping between terminal listings.

Browse with context

Explore the SDKMAN catalog, filter JDKs by vendor, and inspect available updates before reviewing an install-and-activate plan.

Clean up, deliberately

Find verified local-only versions that are no longer in the remote catalog. Defaults and protected pins are excluded; removal needs your review and fresh verification.

Review before you change

Inspect typed mutation plans before confirming. See reclaimable space for removals and clearly labeled disk estimates for installs. Batch steps run sequentially, with individual outcomes—not a global rollback guarantee.

Keep project environments close

Import and export .sdkmanrc files, save named toolchain profiles, and capture environment snapshots. Review missing installs and default changes before restoring a snapshot.

See outcomes, not assumptions

Keep operation history, distinguish unknown availability from verified findings, and use integrity checks or redacted diagnostic exports when something needs attention.

Bring your SDKMAN.
We’ll bring the workspace.

Published release v{{VERSION}}, for Linux amd64 and arm64. The Java runtime is included; you don’t need to install Java to run Zephyr.

SDKMAN is required. Zephyr works with your user’s SDKMAN installation. If you don’t have it yet, follow the official SDKMAN installation instructions.

Your Linux architecture

Choose amd64 for x86-64 PCs, or arm64 for ARM64 machines. Not sure? Run uname -m: x86_64 means amd64; aarch64 means arm64.

Verify before installing

Download the package you want and SHA256SUMS from the same release into the same directory. Run the commands below there, and continue only if your downloaded package reports OK. Stop if verification fails. Checksums check file integrity; they are not an independent signature.

Recommended

AppImage

The simplest way to use Zephyr with full host SDKMAN integration. Download, make executable, and launch.

AppImage for amd64

Download amd64 AppImage
sha256sum --check --ignore-missing SHA256SUMS &&
chmod +x Zephyr-{{VERSION}}-linux-amd64.AppImage &&
./Zephyr-{{VERSION}}-linux-amd64.AppImage

AppImage for arm64

Download arm64 AppImage
sha256sum --check --ignore-missing SHA256SUMS &&
chmod +x Zephyr-{{VERSION}}-linux-arm64.AppImage &&
./Zephyr-{{VERSION}}-linux-arm64.AppImage

Other release bundles

Choose these when they fit your setup. Their integration and trust boundaries differ.

Flatpak

A standalone downloaded bundle, not a Flathub listing or an automatic-update application repository. Host SDKMAN integration is limited and activated host-terminal launch is unsupported. Prefer AppImage or classic Snap for host integration.

Flatpak for amd64

Download amd64 Flatpak
sha256sum --check --ignore-missing SHA256SUMS &&
flatpak install --user ./Zephyr-{{VERSION}}-linux-amd64.flatpak &&
flatpak run com.worxbend.zephyr

Flatpak for arm64

Download arm64 Flatpak
sha256sum --check --ignore-missing SHA256SUMS &&
flatpak install --user ./Zephyr-{{VERSION}}-linux-arm64.flatpak &&
flatpak run com.worxbend.zephyr

Classic Snap

Install the locally downloaded, unsigned release Snap. --dangerous skips Snap Store verification, so verify checksums first. --classic grants broad host access for SDKMAN integration. Snap Store availability is not assumed; see the Store review documentation.

Snap for amd64

Download amd64 Snap
sha256sum --check --ignore-missing SHA256SUMS &&
sudo snap install --dangerous --classic ./Zephyr-{{VERSION}}-linux-amd64.snap

Snap for arm64

Download arm64 Snap
sha256sum --check --ignore-missing SHA256SUMS &&
sudo snap install --dangerous --classic ./Zephyr-{{VERSION}}-linux-arm64.snap
